# MiniFlix 🎬

MiniFlix is a **Netflix-inspired movie web app** that fetches real movie data from **TMDB (The Movie Database) API**. It allows users to **browse popular, top-rated, and upcoming movies**, **search for any movie**, and view **detailed information in a modal**.  

This project demonstrates **JavaScript, HTML, CSS, responsive design, API integration, and interactive UI components**.

---

## Features ✅

- Responsive **mobile navigation** inspired by Netflix
- **Movie grid** with hover overlays showing title, overview, and rating
- **Movie modal** with full details (title, overview, release date, rating)
- **Search functionality** for any movie in TMDB
- **Error handling** for no results or failed API requests
- **Loading spinner** while fetching data
- Fully responsive design
